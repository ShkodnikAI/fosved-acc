# АСС — администрирование собственных сайтов

ИИ-отдел на [Metalogos](https://github.com/ShkodnikAI/Metalogos-) v0.32.0, который ведёт сайты владельца по паспорту: следит за доступностью, сроками домена и сертификата, нормами ТНПА, ценами калькулятора, готовит черновики и мелкие правки. Всё необратимое выполняется только после подтверждения владельца в Telegram.

Первый сайт — ТЕГА ПЛЮС (`tega.plus`). Дальше по тому же паспорту: HUK, Razkadr, КАД (ТЗ §16).

**Статус: этап 0 (подготовка).** В репозитории каркас, минимальный сервер с `/health` и пробы возможностей Metalogos. Функций АСС пока нет.

## Запуск локально

```bash
docker build -t fosved-acc .
docker run --rm -p 10000:10000 fosved-acc
curl localhost:10000/health        # {"checks":{...},"status":"ok"}
```

Пробы Metalogos: `probes/run.sh mlog` (нужны `mlog` 0.32.0, `python3`, `curl`).

## Структура

```
app.mlog        сервер (этап 0: только /health)
core/           ядро: подтверждения, журнал, классы риска, откат
registry/       реестры моделей ИИ и источников данных
adapters/       площадки: render, свой сервер, github, cloudflare
modules/        функции: дежурный, редактор, ТНПА, цены, аналитик, …
profiles/       профили соответствия: витрина, сервис, UGC, оплата
library/ skills/  профили и навыки ролей с моделью
sites/          паспорта сайтов
tests/polygon/  исполняемый полигон модулей
probes/         пробы возможностей Metalogos
data/           данные (не в репозитории)
```
