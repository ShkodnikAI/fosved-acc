# tests/serve/

Тесты под настоящим `mlog serve` (отличие от полигона: тот гоняется через
`mlog run` — интерпретатор). Появился нарядом АСС-1.7 (#24): на движке VM
по умолчанию цикл `each` внутри тела `if` не исполняется молча
(Metalogos-#1336) — полигоны эту ошибку не видят.

- `duty_serve.sh [mlog] [interpreter|vm]` — сценарий 2 полигона Дежурного
  (500 дважды подряд → 1 строка down в incidents) на продовом `app.mlog`
  через внутренний маршрут `/internal/duty/bootstrap`. На `interpreter`
  (как в Dockerfile) — зелёный; на `vm` — ожидаемо красный (ADR-0003),
  сигнал к возврату на VM после исправления Metalogos-#1336.
- `fake_site.py` — фейк-сайт теста (127.0.0.1:18456: /p1 200, /p2 500, /health ok).
- `passport.json` — тестовый паспорт слага `pfav` для фейк-сайта.

Запуск из корня репо: `bash tests/serve/duty_serve.sh mlog interpreter`.
Тест требует чистого `data/` (в CI чекаут свежий) и убирает свои артефакты.
