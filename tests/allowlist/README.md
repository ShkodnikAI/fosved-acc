# tests/allowlist/

Тесты списка разрешённых доменов (наряд АСС-2.1, A.3). Запуск из корня
репо: `bash tests/allowlist/run.sh [путь к mlog]`. Ожидаемо:
`POLYGON allowlist 6/6`. Без сети: `HttpAllowed` — чистая проверка,
`SafeGet` в тесте 3 отказывает до запроса.

Сценарии: https разрешён (паспорт), http отклонён (схема), отказ
SafeGet до запроса + запись `http_denied` в журнале (схема `journal`),
поддомен не открывается, `disabled`-источник не в списке, добавление
`active`-источника с `terms_checked: true` открывает домен без правки
кода. Мутация (`HttpAllowed` всегда true) валит тесты 2–4 — проверена
в отчёте наряда #14.
